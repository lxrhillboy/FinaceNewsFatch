# 习近平对美国国事访问（2026年9月23日至25日）报道汇编

采集时间：2026-09-23 02:20 UTC（北京时间 2026-09-23 10:20；美东时间 2026-09-22 22:20）。

## 此刻能确认的事实

国家主席习近平应美国总统特朗普邀请，于 **2026年9月23日至25日** 对美国进行国事访问，夫人彭丽媛陪同。

截至采集时，公开来源仍是行程预告和背景报道。**尚未检索到专机已经降落、双方已经会面或现场照片已经发布的确认稿。** 白宫记者团日程把抵达欢迎仪式排在美东时间 9月23日 16:10（北京时间 9月24日 04:10）左右，地点为马里兰州安德鲁斯联合基地。

## 三日行程

| 日期 | 安排 | 依据 |
|------|------|------|
| 9月23日 | 习近平、彭丽媛抵达安德鲁斯联合基地。特朗普到机场迎接，并参加抵达欢迎仪式。 | 白宫第一夫人办公室 9月21日声明；记者团日程写明约 16:10 EDT |
| 9月24日上午 | 白宫南草坪、国事楼层、玫瑰园举行国事欢迎仪式。479名各军种军人参加。南车道最高礼遇仪仗、中美国旗、陆军礼号；国事楼层海军陆战队乐队奏两国国歌，两国元首致辞；南草坪总统致敬；玫瑰园阅兵，老近卫军横笛鼓号队、陆战队无声操枪排和鼓号队表演；一架 B-2“幽灵”与四架 F-22“猛禽”飞越。 | 白宫声明 |
| 9月24日白天 | 欢迎仪式后，梅拉尼娅·特朗普与彭丽媛参观史密森尼国立亚洲艺术博物馆。两国元首另行会谈。 | 白宫声明；会谈见多家通讯社对美方官员的转述 |
| 9月24日晚 | 北门廊迎接后，东厅国宴。第一夫人办公室原定 9月23日再公布国宴细节；采集时该补充稿尚未见到。 | 白宫声明 |
| 9月25日上午 | 南门廊迎接，红厅茶叙；随后前往国家档案馆查看与美中关系有关的档案。特朗普夫妇在档案馆送别。 | 白宫声明 |
